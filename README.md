## 📋 Descripción del Proyecto

**Vitabalance** es una aplicación diseñada para el seguimiento y control del bienestar nutricional de los usuarios. Este proyecto ha sido desarrollado como parte de la asignatura de **Desarrollo y Operaciones de Software (DevOps)**, implementando prácticas de integración continua, control de versiones distribuido y trabajo colaborativo.

El objetivo principal es demostrar el ciclo de vida de desarrollo de software utilizando herramientas modernas como **Git, GitHub y GitLab**.

## 🚀 Tecnologías Utilizadas

* **Lenguaje:** Python 3.x
* **Framework Backend:** Flask (para la API y rutas)
* **Control de Versiones:** Git
* **Plataformas:** GitHub / GitLab
* **Entorno:** Virtualenv
